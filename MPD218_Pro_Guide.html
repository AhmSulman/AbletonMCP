02MPD218 Hardware Setup

One-time steps to bring the MPD218 online alongside the APC40 you already have configured.

  1. Plug in the MPD218 via USB (already detected as an active MIDI device on this machine).
  2. In Ableton: Preferences → Link, Tempo & MIDI. Under MIDI Ports, find MPD218 and enable both Track and Remote for Input.
  3. Leave Control Surface set to AbletonMCP (already selected — that's what talks to Claude). You do not select MPD218 itself as a Control Surface; it feeds MIDI directly.
  4. On the MPD218, confirm it's on PGM 1 (factory GM drum kit) and Pad Bank A — this is what the automatic mapping below assumes.
  5. Create or arm a MIDI track with a Drum Rack (or any instrument), set its input to MPD218, channel 10, and arm it for recording/monitoring.
  6. Hit a pad. If you see the Drum Rack pads light up in Ableton, you're live.
If pads trigger the wrong sound Someone may have changed the unit off PGM 1, or a pad bank other than A is selected. Ableton's MIDI monitor (hover the track's input meter, or use a scratch MIDI track with "MIDI From: MPD218 / All Channels" and watch the piano-roll note names) tells you exactly which note a pad is really sending — trust that over any printed chart, including this one.

On-device pro controls FULL LEVEL — forces every pad hit to velocity 127, useful for consistent one-shot triggering. 16 LEVEL — holding a pad transmits all 16 pads at a fixed velocity scaled by position, handy for quick velocity-ramp fills. NOTE REPEAT — holding it plus a pad retriggers that note at a tempo-synced subdivision, great for hi-hat rolls. PGM button cycles the 4 onboard programs, and PAD BANK A/B/C switches the 16 pads to a different note range within the current program. Confirm exact button placement against your unit — layouts are consistent across the MPD218 line but worth a 5-second glance the first time.

04Manual Mapping — Bank B & C for Session Control

Bank A is reserved for drums. Use the other two pad banks, mapped by hand in Ableton, to control the Session grid. This uses Live's own MIDI Map Mode (Ctrl+M) — it captures whatever note a pad actually sends, so it's correct regardless of your unit's exact factory numbering.

Recommended scheme

BankPadsSuggested use
A1–16GM drums (already automatic — leave alone)
B1–16Session clip launch: a 4×4 block of clip slots across 4 tracks × 4 scenes
C1–8Scene launch (fire whole rows)
C9–16Transport & utility: Play, Stop, Record, Overdub, Stop-All-Clips, etc.

Step-by-step (repeat per pad)

  1. Switch the MPD218 to Pad Bank B.
  2. In Ableton, press Ctrl+M (Mac: Cmd+M) to enter MIDI Map Mode — mappable controls outline in blue.
  3. Click the clip slot you want to trigger (an empty or filled slot's launch area).
  4. Hit the corresponding physical pad on Bank B once. Live grabs that note automatically.
  5. Repeat for all 16 slots you want covered, then press Ctrl+M again to exit map mode.
  6. Switch to Pad Bank C and repeat the same click-then-hit process on the Scene Launch buttons (left of each scene) and the transport bar (Play / Stop / Record / Overdub buttons at the top).
Make it permanent MIDI mappings save inside the Live Set (.als). Once you're happy with the layout, use File → Save Live Set as Default Set (or save it as a Template) so every new project opens with Bank B/C already mapped — you only do the Ctrl+M walkthrough once.
Two controllers, two note ranges Because Bank B/C mappings are captured by note number (not by "Bank B" as a concept), if you ever reassign those pads via the MPD Editor software, existing Ableton mappings will point at the old notes. Re-map only the pads you actually changed.
